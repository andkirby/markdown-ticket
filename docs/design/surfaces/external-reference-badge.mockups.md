# External Reference Badges — Mockups

Related spec: [External Reference Badges](external-reference-badge.spec.md).

Review states are embedded in [Ticket Card Mockups](ticket-card.mockups.md) to keep the shared card shell in one place: default configured Jira shortening, same-kind instance disambiguation and full-list details, narrow wrapping/long repository paths and unavailable refs. Search uses the same badges independently of board preferences; the viewer exposes the complete list and capability-gated editing.
